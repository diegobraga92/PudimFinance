## Default Permission

Default permissions for the PudimFinance native plugin (capture, secure storage, biometric, widget)

#### This default permission set includes the following:

- `allow-is-supported`
- `allow-access-granted`
- `allow-open-settings`
- `allow-drain-pending`
- `allow-show-capture-prompt`
- `allow-cancel-capture-prompt`
- `allow-drain-capture-actions`
- `allow-notification-posting-allowed`
- `allow-request-notification-permission`
- `allow-set-capture-settings`
- `allow-secure-get`
- `allow-secure-set`
- `allow-secure-delete`
- `allow-biometric-available`
- `allow-biometric-authenticate`
- `allow-set-widget-spent-today`
- `allow-take-deep-link`
